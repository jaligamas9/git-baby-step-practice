# Python Calculator

A simple Python calculator project with a `Calculator` class for basic arithmetic.

## Usage

Run the example program from this directory:

```bash
python3 main.py
```

The program demonstrates the `Calculator` class from `calculator.py`.

## Methods

- `Calculator.add(first, second)` returns the sum of two numbers.
- `Calculator.subtract(first, second)` returns the difference between two numbers.
- `Calculator.multiply(first, second)` returns the product of two numbers.
- `Calculator.divide(first, second)` returns the quotient of two numbers.
